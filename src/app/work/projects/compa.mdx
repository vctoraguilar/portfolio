## Descripción

Compa es una app móvil Android diseñada para conectar pequeños negocios y fomentar alianzas estratégicas.

## Características principales

- **Desarrollo para Android**: Aplicación móvil desarrollada con Android Studio permitiendo su ejecución en dispositivos Android.
- **Arquitectura Escalable**: Implementación de una arquitectura basada en MVVM, facilitando la mantenibilidad y evolución futura del sistema.
- **Gestión de Usuarios y Alianzas**: Sistema de autenticación seguro y módulos personalizados para la creación y gestión de alianzas estratégicas.
- **Integración de Base de Datos en Tiempo Real**: Sincronización eficiente de datos utilizando Firebase, permitiendo actualizaciones inmediatas en la creación de alianzas y perfiles empresariales.
- **UX/UI Centrado en el Usuario**: Diseño de interfaces minimalistas e intuitivas, enfocadas en la accesibilidad y la facilidad de navegación para usuarios de diversos perfiles, asegurando una experiencia de usuario (UX) fluida y atractiva.
- **Optimización de Rendimiento**: Uso de buenas prácticas de programación y optimización de recursos para garantizar tiempos de carga rápidos y una experiencia estable en diferentes dispositivos móviles.

## Tecnologías usadas

- **Android (Kotlin + Java)**: Para el desarrollo de la aplicación móvil de manera nativa.
- **Firebase Authentication**: Para la autenticación de usuarios y gestión de sesiones.
- **Firebase Firestore**: Para almacenar y consultar datos de usuarios, perfiles y relaciones de amistad en tiempo real.
- **Glide**: Para gestionar la carga de imágenes.
- **Material Design Components**

## Desafíos

- Integración segura de autenticación de usuarios con Google/Firebase.
- Diseño de interfaces adaptables usando CollapsingToolbarLayout, CardView, y RecyclerView.
- Implementación de un sistema de estados dinámicos (amigos, solicitudes enviadas/recibidas, usuarios desconocidos).
- Edición y actualización en tiempo real de datos de perfil y negocio.
- Optimización del rendimiento en carga y visualización de imágenes.

## Aprendizajes

Profundización en el ecosistema Firebase para autenticación y bases de datos en tiempo real.

Mejora en patrones de diseño de interfaz móvil (UI/UX) bajo lineamientos de Material Design.

Adopción de buenas prácticas en estructuración de proyectos Android.

Gestión eficaz de estados de usuario y actualización sincronizada de información en la nube.
