## Descripción

Desarrollo de sistema web de recompensas por participación para jóvenes en riesgo social a través de la implementación de una criptomoneda.

## Características principales

- **Sistema dinámico de participación**: Gestión de usuarios, cuentas financieras y billeteras virtuales.
- **Implementación de criptomoneda RUMI**: Creación y uso de criptomoneda creada específicamente para el proyecto.
- **Transacciones en tiempo real con notificaciones**: Transacciones seguras y verificadas para dar dinamismo a la participación.
- **Sistema de canje de premios**: Tienda virtual con premios a comprar con Rumis.

## Tecnologías usadas

- **ASP.NET MVC**: es un marco de desarrollo web que permite crear aplicaciones dinámicas basadas en el patrón Modelo-Vista-Controlador.
- **C#**: Lenguaje de programación moderno y orientado a objetos. En este proyecto se usa principalmente en la lógica del servidor con ASP.NET MVC.
- **.NET Framework**: plataforma de desarrollo de Microsoft que proporciona un entorno de ejecución administrado para construir y ejecutar aplicaciones.
- **JavaScript + HTML + CSS**: La estructura de Frontend, el estilo visual, interactividad y dinamismo en un interfaz web moderna, atractiva y funcional. 

## Desafíos y aprendizajes

Durante el desarrollo del sistema Rumi , enfrenté retos técnicos relacionados con la creación de una criptomoneda funcional dentro de una aplicación web, la gestión segura de transacciones en tiempo real y la implementación de un sistema de canje confiable. Esto me permitió adquirir conocimientos prácticos en:

Modelado de sistemas financieros básicos (cuentas, transacciones y saldos).
Seguridad en aplicaciones web (autenticación, validaciones y protección contra ataques).
Desarrollo full-stack usando tecnologías como ASP.NET MVC, C#, .NET Framework, HTML, CSS y JavaScript .
Uso de patrones de diseño y buenas prácticas de arquitectura para mantener el código escalable.
Este proyecto reforzó mis habilidades técnicas y también mi compromiso con soluciones tecnológicas que generen impacto social positivo.
